About / 说明

采集说明

一个面向社科大良乡校区的讲座信息索引实验：不生产信息，只把公开信息整理得更可检索。

收录范围

以中国社会科学院大学良乡校区为核心，收录讲座、学术沙龙、工作坊、论坛、研讨会、报告会、讲堂与读书会等公开学术活动。数据来自学校官网、科研处、各学院网站，以及官网转载的微信公众号文章。

字段说明

活动日期

优先取原文“讲座时间 / 活动时间”标注；回顾稿从正文中提取。原文只写“某月某日”时按发布年份推断，跨年时做修正。

校区

依据地点文本判断“良乡校区 / 望京校区 / 线上 / 校外”；原文未写明校区时标记为“未注明”，不做猜测。

主讲人

优先取标题“讲座预告｜姓名：主题”，其次取正文“主讲人 / 主讲嘉宾”字段。

类型

依据标题与栏目关键词归类，如“沙龙”“工作坊”“论坛”“报告会”。

状态

“即将开始 / 今日 / 已结束”由本地日期实时计算，不写入数据。

采集流程

01

栏目发现

梳理学校与各学院官网的讲座、学术活动、通知公告栏目。

02

列表抓取

按分页抓取公开列表，保留标题、发布日期与原文链接。

03

正文解析

提取时间、地点、主讲人、主办单位，识别讲座 / 沙龙 / 工作坊等类型。

04

去重合并

同一活动在学院官网与公众号重复出现时，按标题与日期合并，保留更完整的字段。

更新数据

在项目根目录执行以下命令即可重新采集。脚本只访问公开页面，不登录、不绕过验证，并在请求间加入随机间隔。

python crawler/crawl.py

如需调试，可加 --max-pages 1 只抓每个栏目的第一页。

已知边界

  • 公众号与抖音：微信文章可通过官网转载链接读取；公众号历史消息与抖音视频需要登录，暂不做全量抓取。
  • 日期缺失：部分回顾稿只写“近日”“某日下午”，这类记录会标记“日期待定”。
  • 校区缺失：原文只写“教学楼 308”时无法可靠判断校区，统一标记“未注明”。
  • 重复与遗漏：跨来源合并采用标题相似匹配，仍可能有少量重复或遗漏；欢迎以原文为准。

使用与引用

本站仅聚合公开信息，所有卡片均指向原文。引用活动信息时请以主办单位发布的原文为准；如来源方希望调整或删除收录，请联系维护者处理。
